# 手动部署指南 — 云游甘肃后端更新

## 你需要在 Git Bash 中逐条运行以下命令（需输入密码）

## 步骤 1：上传修改过的文件

```bash
# 进入后端项目目录
cd "C:\Users\34091\Desktop\cc+ds项目\gansu-backend"

# 逐个上传文件（每次会提示输入密码）
scp server.js ubuntu@YOUR_SERVER_IP:/home/ubuntu/gansu-culture-api/server.js
scp data/initData.js ubuntu@YOUR_SERVER_IP:/home/ubuntu/gansu-culture-api/data/initData.js
scp models/Admin.js ubuntu@YOUR_SERVER_IP:/home/ubuntu/gansu-culture-api/models/Admin.js
scp models/Culture.js ubuntu@YOUR_SERVER_IP:/home/ubuntu/gansu-culture-api/models/Culture.js
scp models/Spot.js ubuntu@YOUR_SERVER_IP:/home/ubuntu/gansu-culture-api/models/Spot.js
scp models/Food.js ubuntu@YOUR_SERVER_IP:/home/ubuntu/gansu-culture-api/models/Food.js
```

## 步骤 2：SSH 登录并重启服务

```bash
ssh ubuntu@YOUR_SERVER_IP

# 登录后执行（不要退出 SSH）：
cd /home/ubuntu/gansu-culture-api
npm install --production
pm2 restart gansu-culture-api

# 验证 API
curl http://localhost:3000/api/cultures/1
curl http://localhost:3000/api/spots/101
curl http://localhost:3000/api/foods/7

# 退出 SSH
exit
```

## 提示
- 密码就是服务器那个密码
- 每次 SCP 上传都会提示输密码，6 个文件要输 6 次
- SSH 登录时也要输 1 次
